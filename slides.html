Personal Project — 2026

LINE
Calendar Bot

用自然語言，透過 LINE 管理 Google Calendar 和 Google Tasks — 文字、語音都可以。

Motivation

為什麼做這個？

😤

問題

開啟 Google Calendar app、選日期、填表單 — 太繁瑣。腦袋有個想法時，希望直接說出來就能記錄。

📱

目標

在最常用的通訊軟體 LINE 上，用說話或打字就能新增、查詢、修改行程和待辦事項。

🔒

只給自己用

Bot 只回應 Brian 的 LINE 帳號，沒有多用戶管理的複雜性。

💸

低成本

每月約 $5.5 USD，全部服務合計。不需要訂閱任何 SaaS 工具。

Webhook

LINE 將用戶訊息 POST 到 Render 的 HTTPS endpoint，簽名驗證確保安全。

Claude Tool Use

Claude 理解意圖後呼叫對應工具（Calendar 或 Tasks），形成 agentic loop。

Background Scheduler

APScheduler 在同一個 Render 服務內運行，處理早安通知、提醒、self-ping。

Features

功能一覽

  • Calendar
    新增、查詢、修改、刪除行程 — 「明天下午三點開會」、「這週有什麼？」
  • Tasks
    新增、查詢、完成、刪除待辦事項 — 「記得買牛奶」、「完成買牛奶」
  • Voice
    語音訊息自動轉文字 — m4a → ffmpeg → Google STT → Claude
  • Proactive
    每天 07:00 早安通知（今明行程） + 行程開始前 15 分鐘推送提醒
  • Memory
    對話記憶 10 分鐘、最多 5 輪 — 支援追問、確認、多輪互動
  • Safety
    缺日期/時間先追問；刪除/修改前列出找到的項目確認後才執行
How It Works

訊息流程

文字 / 語音訊息

1
用戶在 LINE 傳訊息
2
語音 → ffmpeg → Google STT 轉文字
voice only
3
載入對話歷史（< 10 分鐘）
4
Claude 判斷意圖，呼叫 Calendar 或 Tasks 工具
5
回覆用戶，存入對話記憶

主動推送

★
每天 07:00 — 今明兩天行程早安通知
★
每分鐘 — 掃描 15 分鐘內開始的行程，推送提醒
★
每 5 分鐘 — self-ping 防止 Render 休眠

所有排程器都在 Render 上運行，你的電腦不需要開著。

Technology

技術選型

🐍 Backend

Python 3.11 FastAPI uvicorn APScheduler

非同步處理 webhook，APScheduler 在同一 process 內跑排程任務。

🤖 AI

Claude Sonnet 4.6 Tool Use

Agentic loop — Claude 自主決定呼叫哪個工具、何時追問用戶。

🔊 Voice

Google STT ffmpeg

LINE 傳來 m4a，ffmpeg subprocess 轉 FLAC，送 Google STT 轉文字。不依賴 pydub。

☁️ Infra

Render.com Google OAuth2

Render 免費方案，self-ping 防休眠。單一 refresh token 覆蓋 Calendar + Tasks + STT。
